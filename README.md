# Qurb_all_contents — переводы и материалы приложения Qurb

Этот репозиторий приложение читает напрямую из ветки **`main`**
(raw-файлы GitHub, запасной путь — CDN jsDelivr), **без тегов** — как 114.
Отправили изменения в `main` — у пользователей обновится само.

**Все переводы хранятся здесь.** В само приложение встроены только арабские
оригиналы (Коран, дуа, азкары, 99 имён), транскрипция и строки экрана
приветствия на 11 языках. Интерфейс и содержимое любого языка — включая
русский, английский и арабский — скачиваются на телефон одним пакетом после
выбора языка на экране приветствия. Запасного языка в приложении нет:
строка, которой нет в пакете языка, остаётся пустой, поэтому каждый ключ
должен быть переведён на все 11 языков.

```
<Язык>/translations_<код>.db   языковой пакет — ОДИН файл на язык (SQLite)
<Язык>/README.txt              что внутри пакета (пишет tools/build_packs.py)
system/<код>.json              строки интерфейса языка — ИСХОДНИК для пакета
                               (ключи «ui114.*», «app_strings.*»,
                               «settings_strings.*», «home_i18n.*» и др.;
                               «ui114.surah.N» — названия сур,
                               «surah_meaning.N» — перевод названий сур,
                               «azkar_cat.*» — названия категорий азкаров)
dua/<код>.json.gz              дуа: названия категорий, заголовки, смысл — ИСХОДНИК
azkar/<код>.json.gz            азкары «После намаза», «Перед сном» — ИСХОДНИК
dhikr/<код>.json.gz            азкары утра и вечера (по номеру) — ИСХОДНИК
names/<код>.json.gz            значения 99 имён — ИСХОДНИК
holidays/<код>.json.gz         важные дни — ИСХОДНИК
hadiths/<код>.json.gz          хадисы (ru, kk, ky, tg) — ИСХОДНИК
policies/privacy_<код>.md      политика конфиденциальности
policies/shariah_<код>.md      шариатское соглашение
                               (читаются ещё до установки языка)
audio/                         азаны, икамат, дуа и сигналы — по запросу
audio/manifest.json            список аудио
manifest.json                  версии и состав пакетов (пишет build_packs.py)
tools/build_packs.py           пересборка пакетов из исходников (system/ и разделы)
tools/section.py               распаковать/упаковать файл раздела для правки
docs/                          отчёты о прошлых обновлениях

Отдельные файлы (их приложение качает по одному, через jsDelivr @main):
quran/arabic.json.gz           арабский текст Корана (запасной, основной встроен)
quran/translit.json.gz         транскрипция аятов латиницей
quran/translations/            переводы Корана по одному файлу (t_<ключ>.json.gz)
quran/editions.json            список изданий
geo/                           названия городов и стран (основное — в пакете языка)
policies/privacy/              страница политики для браузера (GitHub Pages)
```

Языки: `ar` арабский · `en` английский · `ru` русский · `kk` казахский ·
`ky` кыргызский · `az` азербайджанский · `uz` узбекский · `tg` таджикский ·
`tr` турецкий · `ja` японский · `ko` корейский.

## Что внутри пакета

| Раздел SQLite | Что | Куда кладёт приложение |
|---|---|---|
| `system` | все надписи интерфейса | `system/<код>.json` |
| `quran` | переводы Корана этого языка | `quran_translations/t_<ключ>.json` |
| `dua`, `azkar` | тексты дуа и азкаров | `dua/<код>.json`, `azkar/<код>.json` |
| `names99` | 99 имён Аллаха | `names/<код>.json` |
| `holidays` | важные дни | `holidays/<код>.json` |
| `policies` | политика и соглашение | `policies/…` |
| `geo_cities`, `geo_countries` | названия городов и стран | `geo/…` |

Данные в `resources.data` — gzip (UTF-8 JSON или Markdown).

Переводы Корана в пакетах:
`ru` Кулиев, Абу Адель · `en` Saheeh International, Hilali & Khan, Rowwad ·
`kk` Алтай · `ky` Хакимов · `az` Мусаев · `uz` Мансур, Rowwad ·
`tg` Арифи · `tr` Шабан, Шахин, Rowwad · `ja` Сато · `ko` Хамед Чой, Rowwad.

## Как это работает в приложении

1. Первый запуск: экран выбора языка и соглашения (тексты из `policies/`).
2. Пользователь выбирает язык → скачивается **один** `translations_<код>.db`
   (1–2 МБ). Вместе с ним приходят интерфейс, **переводы Корана этого языка**,
   дуа, азкары, 99 имён, важные дни и названия городов.
3. Перевод Корана следует за языком приложения: сменил язык — после
   скачивания пакета суры показываются с переводом на этом языке.
   В арабском интерфейсе перевода Корана и транскрипций нет.
4. Пока пакет не скачан, приложение дальше экрана приветствия не идёт
   (его строки встроены). Если пакет старее `pack_version` приложения, он
   перекачивается при запуске; до конца загрузки новых строк на экране нет —
   другой язык вместо них не подставляется.

## Как обновить надписи

1. Исправьте или добавьте строки в `system/<код>.json` (плоская карта
   «ключ → текст»). Подстановки пишутся в фигурных скобках: `«Сура {surah} из 114»`
   — имена в скобках не переводятся.
2. Пересоберите пакеты:
   ```
   python3 tools/build_packs.py          # все языки
   python3 tools/build_packs.py kk uz    # только эти
   ```
   Скрипт обновит `.db`, `manifest.json`, `README.txt` и покажет, сколько
   строк `ui114.*` в каждом языке ещё не переведено (по сравнению с `en`).
3. Закоммитьте и отправьте в `main`. Чтобы пакет перекачался у всех, кто
   его уже скачал, поднимите `PACK_VERSION` в `tools/build_packs.py` и
   `kPackVersion` в приложении (`LanguagePackStore`); `kPackBytes` — размеры,
   которые печатает скрипт (их видно на экране выбора языка).

Новая фраза в коде приложения: `tr114('ключ')` (и английский вариант в
`lib/core/l10n/ui114.dart`), сама фраза — в `system/*.json`.

## Как обновить содержимое (дуа, азкары, имена, важные дни)

```
python3 tools/section.py unpack dua kk     # dua/kk.json — обычный текст
... правка dua/kk.json ...
python3 tools/section.py pack dua kk       # обратно в dua/kk.json.gz
python3 tools/build_packs.py kk            # пересобрать пакет языка
```

Форматы: `dua` — `{"cat": {ключ: название}, "dua": {ключ: {"t": заголовок,
"tr": смысл, "s": источник}}}`; `azkar` — `{ключ: {"t", "tl", "tr", "s"}}`;
`dhikr` — `{номер: {"tl": смысл, "nar": хадис, "s": источник}}`; `names` —
`{номер: значение}`. Ключ записи — английское название из кода приложения
(идентификатор, на экран не выводится), менять его нельзя.

Проверка, что приложению хватает переводов (из папки приложения):
`python3 tool/l10n_audit.py <путь к этому репозиторию>`.

## Версии

- **pack_version 9** - раздел `dua` заменён полностью: «Хисн аль-Муслим», 246 записей из 122 глав на 10 языках (ru, en, kk, ky, az, uz, tg, tr, ja, ko) вместо прежних 104 дуа; наставления без арабского текста не включены. Ключ записи: `hisn.<глава>.<номер в главе>`; категорий 14 (прежние названия, «Утро и вечер» и «Дуа из Корана» убраны). Для `ar`: только источник (`s`), заголовок в арабском интерфейсе - начало арабского текста. Арабские оригиналы: в приложении (`lib/features/dua/dua_data.dart`). В `azkar/` дописаны недостающие переводы (`tr`) азкаров после намаза и перед сном из тех же текстов. В приложении: `kPackVersion = 9`.

- **pack_version 8** — переводы полностью убраны из приложения и перенесены сюда. В `system/*.json` добавлены строки, которые раньше были зашиты в код: `home_i18n.*` (главный экран), `home_strings.*` (шаблоны дат, дни недели, месяцы), `surah_meaning.N` (перевод названий сур), `azkar_cat.*`, `azkar_strings.count*`, `settings_strings.reciter.*`, `app_strings.hint.*`, `app_strings.review.*` и др. Разделы содержимого: русский и английский тексты дуа, азкаров и 99 имён теперь берутся только из пакета; `dhikr/` пересобран из данных приложения (прежние файлы kk, tr, ja были обрезаны) и добавлен для ru, en и ещё 17 языков; в `azkar/` и `dhikr/` добавлено поле `s` (ссылка на источник), для арабского созданы `azkar/ar` и `dhikr/ar`. `tools/build_packs.py` теперь собирает в пакет и разделы содержимого из `<раздел>/<код>.json.gz`; `tools/export_builtin.py` удалён (встраивать больше нечего). В приложении: `kPackVersion = 8`.

- **pack_version 7** — все 11 языков теперь встроены в приложение (assets/l10n): интерфейс, дуа, азкары, 99 имён, важные дни, хадисы. Пакет из этого репозитория ложится поверх встроенного и только обновляет его. После правки переводов: `python3 tools/build_packs.py`, затем `python3 tools/export_builtin.py <путь к qurb>`. Исправлена установка раздела `azkar`: его три файла (`azkar_*`, `dhikr_*`, `hadiths_*`) писались в один `azkar/<код>.json`, и переводы азкаров затирались хадисами. Отдельные файлы `dua/<код>.json.gz` синхронизированы с пакетами (в них не было переводов смысла). В приложении: `kPackVersion = 7`.
- **pack_version 6** — арабский пакет дополнен разделами `dua` (арабские заголовки дуа) и `names99` (значения 99 имён по-арабски): раньше их не было, и в арабском интерфейсе смысл имён показывался по-английски. Исправлены города: «Медина» — `المدينة المنورة` (было только `المنورة`), лишняя `*` у «Сасаяма». В приложении: `kPackVersion = 6`.
