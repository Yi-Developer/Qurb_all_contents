# Qurb_all_contents — переводы и материалы приложения Qurb

Этот репозиторий приложение читает напрямую из ветки **`main`**
(raw-файлы GitHub, запасной путь — CDN jsDelivr), **без тегов** — как 114.
Отправили изменения в `main` — у пользователей обновится само. В само приложение встроены только арабский
текст Корана и английский как запасной язык интерфейса; всё остальное — здесь
и скачивается вместе с выбранным языком.

```
<Язык>/translations_<код>.db   языковой пакет — ОДИН файл на язык (SQLite)
<Язык>/README.txt              что внутри пакета (пишет tools/build_packs.py)
system/<код>.json              строки интерфейса языка — ИСХОДНИК для пакета
                               (ключи «ui114.*» — экраны раздела «114»,
                               «ui114.surah.N» — названия сур)
policies/privacy_<код>.md      политика конфиденциальности
policies/shariah_<код>.md      шариатское соглашение
                               (читаются ещё до установки языка)
audio/                         азаны, икамат, дуа и сигналы — по запросу
audio/manifest.json            список аудио
manifest.json                  версии и состав пакетов (пишет build_packs.py)
tools/build_packs.py           пересборка пакетов из system/*.json
docs/                          отчёты о прошлых обновлениях

Отдельные файлы (их приложение качает по одному, через jsDelivr @main):
quran/arabic.json.gz           арабский текст Корана (запасной, основной встроен)
quran/translit.json.gz         транскрипция аятов латиницей
quran/translations/            переводы Корана по одному файлу (t_<ключ>.json.gz)
quran/editions.json            список изданий
hadiths/<код>.json.gz          хадисы
dua/, azkar/, names/,          запасные копии разделов (основное — в пакете языка)
holidays/, geo/, dhikr/
policies/privacy/              страница политики для браузера (GitHub Pages)
```

Языки: `ar` арабский · `en` английский · `ru` русский · `kk` казахский ·
`ky` кыргызский · `az` азербайджанский · `uz` узбекский · `tg` таджикский ·
`tr` турецкий · `ja` японский · `ko` корейский.

## Что внутри пакета

| Раздел SQLite | Что | Куда кладёт приложение |
|---|---|---|
| `system` | все надписи интерфейса | `system/<код>.json` |
| `quran` | переводы Корана этого языка | `quran_translations/t_<ключ>.json` |
| `dua`, `azkar` | тексты дуа и азкаров | `dua/<код>.json`, `azkar/<код>.json` |
| `names99` | 99 имён Аллаха | `names/<код>.json` |
| `holidays` | важные дни | `holidays/<код>.json` |
| `policies` | политика и соглашение | `policies/…` |
| `geo_cities`, `geo_countries` | названия городов и стран | `geo/…` |

Данные в `resources.data` — gzip (UTF-8 JSON или Markdown).

Переводы Корана в пакетах:
`ru` Кулиев, Абу Адель · `en` Saheeh International, Hilali & Khan, Rowwad ·
`kk` Алтай · `ky` Хакимов · `az` Мусаев · `uz` Мансур, Rowwad ·
`tg` Арифи · `tr` Шабан, Шахин, Rowwad · `ja` Сато · `ko` Хамед Чой, Rowwad.

## Как это работает в приложении

1. Первый запуск: экран выбора языка и соглашения (тексты из `policies/`).
2. Пользователь выбирает язык → скачивается **один** `translations_<код>.db`
   (1–2 МБ). Вместе с ним приходят интерфейс, **переводы Корана этого языка**,
   дуа, азкары, 99 имён, важные дни и названия городов.
3. Перевод Корана следует за языком приложения: сменил язык — после
   скачивания пакета суры показываются с переводом на этом языке.
   В арабском интерфейсе перевода Корана и транскрипций нет.
4. Пока пакет не скачан (или он старее `pack_version` приложения), надписи
   показываются по-английски; устаревший пакет перекачивается в фоне.

## Как обновить надписи

1. Исправьте или добавьте строки в `system/<код>.json` (плоская карта
   «ключ → текст»). Подстановки пишутся в фигурных скобках: `«Сура {surah} из 114»`
   — имена в скобках не переводятся.
2. Пересоберите пакеты:
   ```
   python3 tools/build_packs.py          # все языки
   python3 tools/build_packs.py kk uz    # только эти
   ```
   Скрипт обновит `.db`, `manifest.json`, `README.txt` и покажет, сколько
   строк `ui114.*` в каждом языке ещё не переведено (по сравнению с `en`).
3. Закоммитьте и отправьте в `main`. Чтобы пакет перекачался у всех, кто
   его уже скачал, поднимите `PACK_VERSION` в `tools/build_packs.py` и
   `kPackVersion` в приложении (`LanguagePackStore`); `kPackBytes` — размеры,
   которые печатает скрипт (их видно на экране выбора языка).

Новая фраза в коде приложения: `tr114('ключ')` (и английский вариант в
`lib/core/l10n/ui114.dart`), сама фраза — в `system/*.json`.

## Версии

- **pack_version 6** — арабский пакет дополнен разделами `dua` (арабские заголовки дуа) и `names99` (значения 99 имён по-арабски): раньше их не было, и в арабском интерфейсе смысл имён показывался по-английски. Исправлены города: «Медина» — `المدينة المنورة` (было только `المنورة`), лишняя `*` у «Сасаяма». В приложении: `kPackVersion = 6`.
- **pack_version 5** — названия палитр оформления: `ui114.cvet` («Цвет»), `ui114.ametist`, `ui114.biryuza` на всех 11 языках. В приложении: `kPackVersion = 5`.
- **pack_version 4** — строки экранов нового дизайна (`ui114.*`) переведены на все
  11 языков (раньше у kk, ky, az, uz, tg, tr, ja, ko было по 5 фраз, у ar — 13,
  остальное показывалось по-английски). Добавлены ключи `ui114.gb`, `ui114.mb`,
  `ui114.kb` (единицы размера) и `ui114.prayer_sovershen_vremya_azkarov`
  (уведомление «азкары после намаза»). В приложении: `kPackVersion = 4`.
- **pack_version 3** (ветка main, без тегов) — строки экранов «114» (`ui114.*`, 357 фраз) и
  названия сур — транскрипцией, как в 114 (ru, kk, ky, uz, tr, en — из 114;
  tg — как ru; az, ja, ko — как en; ar — арабские); исходники надписей вынесены в `system/`,
  добавлен `tools/build_packs.py`, отчёты — в `docs/`.
- **pack_version 2** — раздел `system` со всеми строками интерфейса
  для 11 языков, папка `policies/`.
